# Colorado Roleplay · Bot y panel de Discord

Panel web para configurar y administrar servidores de Discord.

[Panel web](https://crpds.em4nu3l69dll.dev) · [Emanuel Duarte](https://github.com/em4nu3i69dll) · [Portafolio](https://em4nu3l69dll.dev)

![Estadísticas del servidor](imagenes/03-estadisticas.png)

## Funciones

| Módulo | Función |
| --- | --- |
| Acceso | Inicio con Discord y cuentas habilitadas |
| Estadísticas | Miembros, canales, roles y nivel de boost |
| Bienvenidas | Mensajes públicos, privados y variables del usuario |
| Boosteos | Avisos con embed e imagen |
| Embeds | Constructor con vista previa y mensajes guardados |
| Autoroles | Configuración de roles por servidor |
| Logs | Eventos de mensajes, miembros, canales y roles |
| Backups | Exportación e importación de estructura y configuración |
| Emojis y stickers | Carga de archivos, biblioteca y exportación |
| Voz temporal | Canales con categoría, nombre, límite y bitrate configurables |
| Soporte | Equipo, solicitudes, historial y reseñas |
| Streamers | Configuración de alertas de directo |
| Moderación | Reglas por canal y Anti-Punto |
| Comandos | Respuestas y permisos configurables |

## Tecnologías

Node.js · Express · Discord.js · SQLite · EJS · Discord OAuth2 · Cloudflare Turnstile
